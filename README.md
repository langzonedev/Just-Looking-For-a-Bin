# Just Looking for a Bin

A quiet lunchtime browser game from Lang Systems Arcade. Empty a takeaway coffee
cup into the bushes and watch the lunch table get progressively rowdier.

[Play on GitHub Pages](https://langzonedev.github.io/Just-Looking-For-a-Bin/)

Drag sideways to move the cup. Pull down and hold to tip it and pour, then
release to straighten it. With the playfield focused, use Left and Right to
move and hold Space to pour. Sound is optional.

Serve this directory over HTTP with `python3 -m http.server 8000` for local
development. No build step or external dependencies are required.
